# 统一口与共享服务

本目录是现用的统一AstrBot插件及独立中转/记忆/支持程序。主体入口为 `main.py`，程序服务入口见 `deploy/systemd`。插件端和独立服务端需要同版本代码；配置与数据属于运行目录，不放在源码树里。

文件职责见[模块地图](../../docs/MODULES.md)，完整装配与路径见[部署说明](../../docs/DEPLOYMENT.md)。`vendor/` 代码保留AGPL-3.0声明；B站底层客户端另行安装。

配置示例位于 `config/examples`。真实 `api.json` 不入库，仓库只保留空密钥示例。绝不把观察数据库、输出账本、聊天图片和浏览器用户目录复制进本目录后提交。
